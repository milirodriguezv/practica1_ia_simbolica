# Práctica 1 de IA simbólica

| Carpeta | Ejercicio |
|---|---|
| `ejercicio_1/` | Satisfacibilidad booleana: coloreado de mapas con un agente lógico y DPLL |
| `ejercicio_2/` | Ontología de una carta italiana y razonamiento sobre categorías |
| `ejercicio_3/` | Búsqueda informada: planificador de rutas para un rover en Marte con A* |

## Instalación

Hace falta Python 3.12 o posterior (probado con 3.12 y 3.14). Un único entorno
sirve para los tres ejercicios:

```
python -m venv .venv
.venv\Scripts\activate          # en Linux o macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Cada ejercicio se ejecuta desde su propia carpeta; las instrucciones están en
su README.
